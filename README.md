# Workshop

Список коктейлей. Учебный воркшоп от 23 августа 2023 года.

## Что умеет приложение

На экране список названий. При открытии приложение запрашивает коктейли у `partyshaker.online`.

В проекте также лежит клиент этого API: вход, ингредиенты, бар, избранное и оценки. На экран из этого подключен только список коктейлей.

## Курс

Воркшоп по API PartyShaker. Сетевой слой написали Alexandr Rodionov и Anna Shuryaeva. Экран собрал Илья Шаповалов.

## Стек

SwiftUI, Combine, URLSession.

## Запуск

```bash
git clone https://github.com/dpogonia/Workshop-PartyShaker.git
cd Workshop-PartyShaker
open Workshop23.08.xcodeproj
```

Запустите схему **Workshop23.08** на симуляторе iPhone. Для списка нужен доступ к `partyshaker.online`.
